# 舍入与口径说明（登记表模板）

金额复算前，必须先固定口径。**任何一格为空或相互矛盾时，暂停涉及该金额的比较与汇总，报口径不明，不猜测、不默认。**

## 1. 币种

本脚本已知币种码（ISO 4217）：`CNY`、`USD`、`EUR`、`JPY`、`GBP`、`HKD`。
出现其他币种 → 拒绝（未知币种）。不同币种金额之间不做自动换算比较。

## 2. 单位

| 代码 | 含义 | 换算 |
|---|---|---|
| `yuan` | 元 | 1 元 |
| `wan_yuan` | 万元 | 1 万元 = 10000 元 |

- 汇总（`sum`/`multiply`）与舍入（`round`）只支持以**元**为计算单位；结果单位固定为 `yuan`。项目以万元计价的，请先用 `convert_unit` 统一为元后重提。
- **单位冲突不静默降级**：契约之外的 `unit` 字段（如给 `sum` 附带 `unit:"wan_yuan"`）会被拒绝——调用方必须先统一口径再重提，脚本不猜测该字段语义，避免把万元数当元数使用。
- 书面文件写"万元"而表格数字疑似元（或反之）时：先登记疑点，暂停比较，待项目澄清。

## 3. 含税口径

| 代码 | 含义 |
|---|---|
| `tax_inclusive` | 含税价 |
| `tax_exclusive` | 不含税价 |
| `not_applicable` | 不适用（如非税金额、数量等） |

含税与不含税金额不得直接相加比较；确需换算时必须已知税率，且税率作为显式输入另行记录，不在本脚本内默认。

**行内口径冲突拒绝**：行项目（`line_items` 内的对象）只允许 `quantity` 与 `unit_price` 两个键；行内出现 `tax_basis` 等口径字段与顶层口径冲突时，脚本拒绝整个请求，要求调用方统一口径后重提，不静默丢弃任何一方。

## 4. 舍入约定

- 模式名共 8 种：`ROUND_HALF_UP`（四舍五入）、`ROUND_HALF_EVEN`（银行家舍入）、`ROUND_DOWN`、`ROUND_UP`、`ROUND_CEILING`、`ROUND_FLOOR`、`ROUND_HALF_DOWN`、`ROUND_05UP`（先向零取整到步长；截断结果末位为 0 或 5 时向外再加一个步长）。
- `increment` 常用值：`"0.01"`（到分）、`"1"`（到元）、`"0.05"`（到 5 分）；步长必须为正，零/负拒绝。
- `rounding` 字段：整体省略表示不做额外舍入（保留精确十进制结果，`rounded:false`）；字段值写 `null` 或非对象会被拒绝（契约要求对象或省略）。`round` 操作必须提供 `rounding`。
- 舍入全程在整数域精确完成（精确的商与余数比较），不存在中间舍入跨越最终舍入边界的情形。
- 项目另有规定（如"单价保留两位、合计不另舍入"）时以项目规定为准，并在登记表"项目专门约定"列记录。

## 5. 数值上限（超界结构化拒绝）

| 限制 | 上限 |
|---|---|
| 单个数值字符串长度 | 128 字符 |
| 单个数值有效位数 | 64 位 |
| 十进制指数绝对值 | 500 |
| `sum.operands` 项数 / `multiply.line_items` 行数 | 1000 |
| 输出 JSON 文本长度 | 128 KiB |

超界一律返回 `status:"rejected"`（退出码 2）；有限非零数绝不因超出计算范围而被静默当作 0。

## 6. 文件与覆盖策略

- 输入文件只读；输出只允许写到**尚不存在**的路径（排他创建）。
- 输出与输入同路径、互为符号链接/硬链接，或输出指向已存在的普通文件/符号链接/目录 → 拒绝（退出码 3），不写任何文件。
- 重跑同一计算：换新输出路径，或由调用方先删除旧输出；脚本不代为覆盖。

## 8. 空值与异常处理约定

- 读不到金额 → 记录"未读到"，**不**按 0 参与汇总。
- 出现 NaN / Infinity / 无法解析的数字 / 超出上限的数字 → 拒绝。
- 单价、数量、合计三者不一致 → 给出候选修正，注明以招标文件修正规则为准；不自动判定无效。
